# 🇯🇵 טיול יפן — מעקב הוצאות

PWA למעקב אחרי ההוצאות בטיול ליפן: כל הוצאה נרשמת במטבע שבו שולמה בפועל (¥ ין, $ דולר, € יורו או ₪ שקל — למשל כרטיס טיסה שמשולם בדולר), עם המרה אוטומטית לשקלים בכל הדשבורדים והסיכומים, פילוח לפי קטגוריה ומעקב תקציב.

## תכונות

- **רישום הוצאות מרובה-מטבעות** — כל הוצאה נשמרת במטבע המקורי שלה (¥/$/€/₪), תאריך, קטגוריה, אמצעי תשלום (מזומן/כרטיס) והערה חופשית
- **דשבורד** — סה"כ הוצאות בשקלים, יתרת תקציב, יום נוכחי בטיול, גרף עוגה לפי קטגוריה
- **תקציב** — תקציב כולל ותקציב לכל קטגוריה בנפרד (בשקלים), עם פס התקדמות שמתריע כשחורגים
- **שערי חליפין** — שער נפרד לכל מטבע (¥/$/€) הניתן לעדכון ידני; כל סכום מוצג גם עם ההמרה המקורית וגם בשקלים
- **רשימת הוצאות** — מקובצת לפי יום, עם סינון לפי קטגוריה ועריכה/מחיקה מהירה
- **PWA** — ניתן להתקנה על המסך הראשי באייפון/אנדרואיד

| שכבה | טכנולוגיה |

## הרצה

### 1. Supabase

1. צרו פרויקט חינמי ב-[supabase.com](https://supabase.com)
2. היכנסו ל-**SQL Editor** → הדביקו את התוכן של `supabase/migrations/001_initial.sql` → Run
3. העתיקו את ה-**Project URL** וה-**anon key** מתוך Settings → API

### 2. משתני סביבה

```bash
cp .env.local.example .env.local
# ערכו את .env.local עם פרטי הפרויקט שלכם
```

### 3. הרצה מקומית

```bash
npm install
npm run dev
# → http://localhost:3000
```

### 4. פריסה (Vercel — מומלץ)

```bash
npm install -g vercel
vercel
# הוסיפו את משתני הסביבה בדשבורד של Vercel
```

## שימוש

### הוספת הוצאה
לחצו על כפתור ה-**+** הצף → בחרו תאריך, קטגוריה, סכום ומטבע (¥/$/€/₪ — למשל כרטיס טיסה בדולר), אמצעי תשלום, והוסיפו הערה אם רוצים

### עריכה/מחיקה
לחצו על הוצאה קיימת ברשימת "הוצאות" כדי לערוך או למחוק אותה

### הגדרת תקציב
בעמוד "תקציב" — הגדירו את תאריכי הטיול, תקציב כולל בשקלים, שער חליפין לכל מטבע (¥/$/€ ← ₪), ואופציונלית תקציב נפרד לכל קטגוריה

## מבנה האפליקציה

```
src/
  app/
    page.tsx               # דשבורד — סיכום, גרף קטגוריות, הוצאות אחרונות
    expenses/page.tsx       # רשימת הוצאות מלאה, מקובצת לפי יום עם סינון
    budget/page.tsx         # הגדרת תקציב ותאריכי טיול
    api/
      expenses/            # CRUD להוצאות
      budget/               # שמירת/קריאת הגדרות התקציב
  components/
    Navigation.tsx          # ניווט תחתון (מובייל) / עליון (דסקטופ)
    CategoryChart.tsx        # גרף עוגה — הוצאות לפי קטגוריה
    ExpenseModal.tsx        # מודל הוספה/עריכה של הוצאה
  lib/
    supabase/               # לקוחות Supabase (client + server)
    currency.ts             # קטגוריות, מטבעות נתמכים, פורמט וסכום, המרת מטבע לשקל
  types/index.ts
supabase/
  migrations/001_initial.sql
```
